Smart-Rename: Enterprise Edition

Comprehensive documentation for a Python script designed for intelligent file and content renaming in enterprise workflows.

v2.1.0 MIT License Python 3.8–3.13

Overview

Smart-Rename: Enterprise Edition is an open-source Python script for advanced file and content renaming, optimized for enterprise environments. It supports batch operations, respects `.gitignore` patterns, handles non-ASCII text, and offers YAML-based configuration for complex workflows.

Key highlights:

  • Parallel processing for large-scale renaming.
  • Automatic encoding detection with `chardet`.
  • Case-preserving text replacements.
  • Support for over 50 text file extensions (e.g., `.py`, `.txt`, `.md`).
  • Dry-run mode to preview changes safely.
  • Enterprise-grade support via Tidelift.

Features

Batch Renaming

Rename files and directories in bulk with precise control.

Content Replacement

Update text within files, preserving encoding and formatting.

Gitignore Support

Respect `.gitignore` patterns to avoid unwanted changes.

Non-ASCII Handling

Seamlessly process Unicode text, including Persian.

Parallel Processing

Utilize multiple workers (1–16) for faster operations.

Dry-Run Mode

Preview changes without modifying files.

Installation

Requirements

  • Python 3.8–3.13
  • pip package manager

From Source

git clone https://github.com/memarzade-dev/smart-rename.git
cd smart-rename
pip install -r requirements.txt

Standalone Usage

Run the script directly after downloading:

python smart_rename_pro.py --help

Dependencies (listed in `requirements.txt`):

  • chardet>=5.2.0,<6.0
  • pyyaml>=6.0.2,<7.0
  • pathspec>=0.12.1,<0.13

Usage

Run the script with:

python smart_rename_pro.py --directory <path> --search <term> --replace <term> [options]

Options

Option Description
--directory Target directory (required)
--search Text to search for
--replace Replacement text
--workers Number of parallel workers (1–16, default: 4)
--config Path to YAML config file
--dry-run Preview changes without applying

Configuration

Use a YAML file to specify settings:

search_term: "old"
replace_term: "new"
exclude_extensions: [".log", ".bin"]
include_extensions: [".py", ".txt"]

Example usage with config:

python smart_rename_pro.py --directory ./project --config config.yaml

Examples

Rename Files

python smart_rename_pro.py --directory ./docs --search draft --replace final

Replace Content

python smart_rename_pro.py --directory ./src --search "Copyright 2023" --replace "Copyright 2024"

Non-ASCII Renaming

python smart_rename_pro.py --directory ./data --search "زرین پال" --replace "هدف"

Dry Run

python smart_rename_pro.py --directory ./project --search old --replace new --dry-run

Using YAML Config

python smart_rename_pro.py --directory ./app --config rename.yaml
