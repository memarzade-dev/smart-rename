Get Started in Minutes

Follow these simple steps to install and run Smart Rename Pro.

Step 1: Installation

First, clone the repository and install the necessary Python dependencies.

git clone https://github.com/oxychain-dev/smart-rename.git
cd smart-rename
pip install -r requirements.txt

Step 2: Basic Usage

Execute a simple find-and-replace operation from the command line.

python smart_rename_pro.py --directory ./my-project --search "OldName" --replace "NewName"

Step 3: Advanced Usage

For complex scenarios, use a `config.yml` file to define your operations.

# config.yml
search_term: "OldComponent"
replace_term: "NewService"
exclude_extensions:
  - .log
  - .tmp
python smart_rename_pro.py --directory ./my-project --config config.yml
