🌟 Smart Rename Pro: Enterprise Edition 🌟

An Intelligent Refactoring Engine

More than a utility, Smart Rename Pro understands your code's structure, performing complex batch renaming on files, directories, and their content while preserving case patterns.

Core Capabilities

🧠

Intelligent Case

Automatically detects and applies `camelCase`, `PascalCase`, `snake_case`, and `UPPERCASE` patterns.

🔍

Content Replacement

Searches and replaces terms deep within the content of your text-based files.

⚙️

Config Driven

Manage complex operations easily using a clear and simple `config.yml` file.

⚡️

Concurrency Support

Utilizes multiple worker threads for significantly faster processing of large projects.

🙈

Ignore File Support

Natively respects rules in `.gitignore` files to avoid unwanted changes.

🧪

Dry Run Mode

Preview all potential changes safely without modifying a single file on your disk.

Get Started in 3 Steps

1

Install

Clone the repository and install the dependencies.

git clone https://github.com/oxychain-dev/smart-rename.git
cd smart-rename
pip install -r requirements.txt
2

Run a Basic Command

Execute a simple find-and-replace operation.

python smart_rename_pro.py --directory ./my-project --search "OldName" --replace "NewName"
3

Use a Config File

For advanced usage, run the tool with a configuration file. 

python smart_rename_pro.py --directory ./my-project --config config.yml
